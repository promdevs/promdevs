# AI tool brand marks

These marks identify tools PromDevs works with. They do not imply partnerships,
endorsements, or certifications beyond the separate Lovable and Replit credential.
Brand names and marks remain the property of their respective owners.

## Sources

- Replit: [SVGL source](https://github.com/pheralb/svgl/blob/main/static/library/replit.svg), [brand kit](https://replit.com/brandkit).
- Lovable: [SVGL source](https://github.com/pheralb/svgl/blob/main/static/library/lovable.svg), [brand resources](https://lovable.dev/brand).
- Claude: [SVGL source](https://github.com/pheralb/svgl/blob/main/static/library/claude-ai-icon.svg), [Claude](https://claude.ai/).
- Codex: [SVGL source](https://github.com/pheralb/svgl/blob/main/static/library/codex_light.svg), [Codex](https://openai.com/codex/). This asset uses the OpenAI brand mark to identify Codex.
- Cursor: [SVGL source](https://github.com/pheralb/svgl/blob/main/static/library/cursor_light.svg), [brand resources](https://cursor.com/brand).
- Base44: the two brand-mark paths extracted without geometry changes from the header logo on [Base44's website](https://base44.com/), retrieved October 3, 2026. The adjacent wordmark is rendered as text, so only the symbol is stored here.

SVGL's MIT notice is included in `SVGL-LICENSE.txt`; it does not grant rights to
third-party trademarks. Source colors are retained in the SVG files. The tools
strip uses CSS filters to display monochrome marks in light and dark themes.
Assets are bundled locally rather than hotlinked. No logo package is required.
